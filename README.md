# WORKAI — instaladores

Este repositório só guarda os instaladores do WORKAI (o código fica em um repositório privado).

Baixe a versão mais recente em [Releases](https://github.com/avelinocneto/workai-releases/releases/latest): `WORKAI-<versão>-win-x64.exe`.

O app instalado procura versões novas aqui sozinho e se atualiza.
